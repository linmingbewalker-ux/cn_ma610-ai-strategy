## 2. 跑起来的四步

**① 装 SDK** —— 你所在期货平台的 Python 策略端，SDK 包名 `pythongo`（版本 1.0.0）。
> ⚠️ **SDK 不属于本项目，也不随包分发** —— 它由平台方提供，请自行向你的平台获取。本项目只引用它的接口（如 `from pythongo.ui import BaseStrategy`），不含其任何源码。

**② 放 key** —— 二选一：
- **文件方式**：在你的 API 目录里建 `API` 文件夹，把 key 存成明文 `.txt`：
  | provider | 文件名 |
  |---|---|
  | deepseek | `deepseek_api.txt` |
  | 豆包 / doubao | `豆包_mini.txt` |
  | 智谱 / zhipu | `智谱api.txt` |
  | kimi | `KIMI.txt` 或 `kimi_api.txt` |
- **环境变量方式**（更省事）：设 `DEEPSEEK_API_KEY` / `ARK_API_KEY` / `ZHIPU_API_KEY` / `KIMI_API_KEY`。

**③ 改一行路径** —— 打开 `api_keys_config.py`，把占位符换成你自己的目录：

```python
DEFAULT_API_DIRS = [
    r"<你的API目录>/API",     # ← 把 <你的API目录> 换成真实路径
]
```
> 没改之前 `load_keys()` 会返回空，策略报"未找到 API Key"，**这是正常的**，不是坏了。

**④ 载入** —— 在交易平台的 Python 策略端里加载 `AI_multiagent_debate_v2_翻修.py`，先跑**信号版 / 模拟**，确认方向对了再上真钱。

## 4. 想改代码，怎么和 AI 配合

作者的经验做法（原话整理）：

1. **在 C 盘以外的盘**单独建一个文件夹放你的修改版 —— 别动平台实际读取的 live 目录。
2. 把 **`pythongo-1.0.0` SDK 压缩包 + 本文件夹**一起扔给 AI，让 AI 照着官方 Demo 改，**别让它从零研发**。
3. 改完**必须重启策略实例**才生效；改完先跑零成本的场景测试。
4. 诊断问题**先抓日志和代码证据**，别靠记忆猜。
